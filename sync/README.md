# 每天自動更新試算表

```
XQ log ─► xq_daily_report.py（14:00）─► C:\XS\data\*.csv
                                         │
                              sheet_sync.py（報表跑完接著跑）
                                         │  HTTPS POST＋密碼
                                         ▼
                Google Apps Script（Code.gs，綁在「策略管理」試算表）
                                         │  寫入 _trips / _positions / _daily / _sync_log
                                         ▼
               試算表公式算出 總覽 ─► 網頁 dashboard 每 5 分鐘讀一次
```

## 先知道

網頁和這個 repo 都是公開的，網頁裡寫著試算表的 ID。試算表改成「知道連結的任何人可檢視」之後，**任何拿到網址的人都看得到全部交易紀錄**（不含任何密碼）。不想公開就不要開分享，網頁會顯示讀不到。

## 一次性安裝

### 1. 試算表這邊（你自己做，大約 3 分鐘）

1. 打開「策略管理」試算表 → 上方選單「擴充功能」→「Apps Script」。
2. 把編輯器裡原本的內容全部刪掉，貼上 [`Code.gs`](Code.gs) 的全部內容，按儲存（磁碟片圖示）。
3. 上方函式下拉選單選 `setup`，按「執行」。第一次會要你授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。這是你自己寫的程式，Google 才會這樣提醒。
4. 下方「執行記錄」會出現一行 `SYNC_TOKEN：……`，這就是密碼，先留著，**不要貼給任何人**。
5. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（沒有密碼的請求會被擋掉）
   
   按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
6. 試算表右上「共用」→ 一般存取權改成「知道連結的任何人」→ 角色「檢視者」，網頁才讀得到。

### 2. 電腦這邊（C:\XS\tools）

1. 放上 `sheet_sync.py`。
2. 照 `sheet_sync.example.json` 建一個 `sheet_sync.json`，填上第 1 步拿到的網址和密碼。這個檔和 `notify.json` 一樣只放在你電腦上。
3. 先試讀檔：`python sheet_sync.py --dry-run`
4. 第一次把歷史資料全部送上去：`python sheet_sync.py --full`
   （會整份覆蓋試算表的交易和持倉，11/3 從報表信手動補的那幾列會被正式資料取代。）
   **一定要先做這一步再做第 5 步**：每日同步只會新增、更新，不會刪舊的列；手動補的那趟 trip_id 沒有秒數，沒先全量覆蓋的話會和正式資料重複。
5. 在 `每日報表.bat` 報表那一行後面加一行：

   ```bat
   python "%~dp0sheet_sync.py"
   ```

之後每個交易日 14:00 報表跑完就會自動推上去。

## 之後要注意

- 改了 `Code.gs` 之後，要到「部署」→「管理部署作業」→ 鉛筆 →「版本：新版本」→「部署」，網址不變但才會用新程式。
- 用報表程式重算、改寫過去日期的資料之後，要再跑一次 `python sheet_sync.py --full`；每日同步不會刪掉已經不存在的舊趟。

## 每天的行為

- 送最近 5 個交易日的 trips（用 trip_id 判斷新增或更新，所以重跑不會重複）、最新一天的持倉、整份 daily_pnl.csv。某天沒推成功，下一次會自動補上。
- 結果寫在 `C:\XS\report\sheet_sync.log`，試算表的 `_sync_log` 分頁也會多一列。
- 任何一筆資料格式不對（例如缺 trip_id、日期看不懂），那次整批不寫，log 會寫原因。
- 試算表 `_trips` 等分頁的第一列欄名如果被改過，程式會拒絕寫入，避免寫錯欄。
- 持倉全部出場那天（持倉檔只有標題列，或沒有持倉檔但 daily_pnl 的 ALL 寫 0 檔），會把試算表上舊的持倉清掉，網頁才不會停在前一天的持倉。
- 網頁右上角會顯示「電腦 M/D HH:MM 推送」，超過 2.5 天沒推送會變紅提醒。
